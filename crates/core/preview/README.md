# Preview pictures

Sample faces, a banner, server icons and a stream thumbnail for `bot preview`, so the dashboard
can be looked at with pictures and no Discord connection. Served from this folder at
`/preview/<file>` only in preview mode; never compiled into the bot.

- `av1.jpg` to `av12.jpg`: placeholder portraits from randomuser.me, made for mockups.
- `banner.jpg`, `stream.jpg`: placeholder photos from picsum.photos (Unsplash licence).
- `lake.jpg`, `icon-b.jpg`: "Sunrise over Mud Hen Lake" by blmcalifornia, Public Domain Mark 1.0
  (https://www.flickr.com/photos/50976304@N07/52989471233).
- `icon.png`: the owner's server icon.
